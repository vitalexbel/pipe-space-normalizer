# Pipe Space Normalizer

[English](README.md) | Русский

Плагин для Obsidian, удаляющий лишние пробелы-отступы в Markdown-таблицах.

Obsidian автоматически дополняет ячейки таблиц пробелами, выравнивая столбцы
в исходном тексте. В редакторе это выглядит аккуратно, но раздувает файлы и
зашумляет историю git: правка одной ячейки переформатирует всю таблицу, и в
diff попадают все строки.

Pipe Space Normalizer сжимает отступы до одного пробела вокруг содержимого
ячейки — файлы остаются компактными, а diff чистыми.

## До и после

До:

```markdown
| Name  | Value |
| ----- | ----- |
| alpha | 1     |
| beta  | 22    |
```

После:

```markdown
| Name | Value |
| --- | --- |
| alpha | 1 |
| beta | 22 |
```

## Возможности

- Один пробел вокруг содержимого ячейки: `| cell |`
- Строки-разделители сжимаются до `---`, маркеры выравнивания сохраняются
  (`:---`, `---:`, `:---:`)
- Корректно обрабатываются экранированные `\|`, викиссылки `[[note|alias]]`
  и инлайн-код
- Блоки кода (``` и ~~~) не затрагиваются
- Опция «Применять при сохранении»: нормализует таблицы при нажатии
  Ctrl+S / Cmd+S
- Не срабатывает при фоновом автосохранении — курсор не прыгает при наборе
  текста в Live Preview
- Совместим с Linter и другими плагинами: исходная команда сохранения
  всегда выполняется, ничего не блокируется
- Позиция курсора, прокрутка и история отмен сохраняются (построчная
  замена вместо полной перезаписи документа)
- Работает на десктопе и мобильных
- Интерфейс на языке программы (английский и русский)

## Команды

| Команда | Действие |
| --- | --- |
| Нормализовать таблицы в текущем файле | нормализовать все таблицы активного файла |
| Нормализовать таблицы во всех Markdown-файлах | нормализовать таблицы во всём хранилище |

Обеим командам можно назначить горячие клавиши в разделе
Настройки → Горячие клавиши.

## Настройки

| Настройка | По умолчанию | Описание |
| --- | --- | --- |
| Применять при сохранении | включено | нормализовать таблицы при сохранении через Ctrl+S / Cmd+S; фоновое автосохранение не затрагивается |

Настраивать горячие клавиши не нужно: стандартное сохранение работает как обычно.

## Установка

### Через BRAT

1. Установить и включить плагин BRAT.
2. Выполнить команду «BRAT: Add a beta plugin for testing».
3. Вставить `https://github.com/vitalexbel/pipe-space-normalizer` и подтвердить.
4. Включить Pipe Space Normalizer в разделе Настройки → Сторонние плагины.

### Вручную

1. Скачать `main.js` и `manifest.json` из последнего релиза.
2. Создать папку `ХРАНИЛИЩЕ/.obsidian/plugins/pipe-space-normalizer/`
   и положить туда оба файла.
3. Включить плагин в разделе Настройки → Сторонние плагины.

## Примечания

- Табличными считаются только строки, начинающиеся и заканчивающиеся `|`.
- Плагин написан на чистом JavaScript, сборка не требуется.
- Нормализация идемпотентна: повторный запуск ничего не меняет.
